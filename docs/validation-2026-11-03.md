# 2026-11-03 账号维护与迁移验收

## 本轮交付

1. 动态热池、冷池维护、跨通道单飞校验、活性缓存、失败退避，以及设置页与监控。
2. 账号远程信息、图片额度和恢复时间同步；成功出图扣减本地已知额度。
3. 同身份归并、兼容旧格式导入，保留未知字段与关联账号；管理员可完整导出凭据及元数据。
4. PowerShell 完整备份与恢复，覆盖数据库、图片、原始报文与部署配置。
5. PostgreSQL、竞态检测、模拟并发、持续负载、UI 及恢复演练。

本轮不实现 webhook。账号仍启动全量加载，调度仍使用内存索引；部署保持单实例。

## 备份恢复演练

使用两个独立 Compose 项目，账号、密钥和文件全部为虚构数据。

1. 源环境含两条账号、一条调用日志、一张 fixture 图片、一份原始报文。备份结束后源 core 自动恢复运行。
2. 恢复到空目标后 `/readyz` 正常；账号完整字段、日志数量及图片/报文 SHA256 一致。
3. 对已有数据的目标再次执行默认恢复，按预期拒绝，不删除现有数据。
4. 向目标加入额外日志及文件，再显式 `-ReplaceExisting` 恢复：备份内容保留，额外数据被移除。
5. 复制并损坏备份 dump 后，清单校验按预期拒绝；拒绝发生在创建任何容器之前。

恢复使用显式指定的目标 Compose 与环境文件，不自动覆盖本地 `.env`。备份包含完整凭据，应按数据库备份管理。具体操作见 [账号维护、迁移与备份恢复](account-lifecycle-and-recovery.md)。
